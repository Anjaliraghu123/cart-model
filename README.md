#  Add to Cart Using Modal – ReactJS

This project is a ReactJS application that fetches product data from the **Fake Store API** and allows users to add products to a cart using a **modal interface**.  
The application demonstrates state management, component-based architecture, and responsive UI design.

---

##  Features

- Fetch products from Fake Store API
- Display products in a responsive 4-column layout
- Add products to cart
- Alert shown when adding duplicate product
- Cart item count displayed in Navbar
- Cart displayed inside a modal
- Remove items from cart
- Fully responsive (Desktop & Mobile)
- Clean and readable code structure
